<b>Jogo Valeti</b>
<br>
<br>
Uma Visual Novel desenvolvida com a engine Ren'Py.
<br>
<p>📋 Sobre o Projeto
Valeti é um jogo focado em narrativa e tomada de decisão. 
O projeto explora a fantasia, onde as escolhas da pessoa jogadora moldam o curso da história e os relacionamentos entre os personagens.
<br>
Este projeto foi criado e desenvolvido por Leticia Martins Vianna e Vanessa Martins Vianna.
</p>
🎮 Funcionalidades
Sistema de Escolhas: Caminhos ramificados que levam a múltiplos finais.
Galeria de Imagens: Visualização de CGs desbloqueadas durante a gameplay.
Histórico (Log): Acesso rápido aos diálogos passados.
Salvamento Personalizado: Vários slots para gerenciar diferentes rotas.
</p>
<p>
🛠️ Tecnologias
  <br>
Engine: Ren'Py 8.x (Python 3 base)
Linguagem: Ren'Py Script / Python
Interface: Custom GUI (Screen Language)
</p>
<p>
🚀 Como Executar
<br>
Existem duas formas de acessar o jogo:
  <br>
  <br>
Para Jogadores:
Baixe a versão compilada na seção Releases.
Extraia o arquivo .zip.
Execute o arquivo Valeti.exe (Windows) ou Valeti.sh (Linux).
  <br>
  <br>
Para Desenvolvedores (Editar o Código):
Instale o Ren'Py Launcher.
Clone este repositório dentro do seu diretório de projetos do Ren'Py:
Bash
git clone https://github.com/seu-usuario/valeti.git
Abra o Ren'Py Launcher, selecione "Valeti" e clique em Launch Project.
</p>
